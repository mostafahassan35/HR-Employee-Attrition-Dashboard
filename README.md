# HR Employee Attrition Dashboard

## 📊 Project Overview

An interactive Power BI dashboard designed to analyze employee attrition and identify patterns across different employee characteristics.

## 🎯 Key Analysis

* Employee Attrition & Attrition Rate
* Attrition by Department
* Attrition by Age Group
* Attrition by Salary Range
* Attrition by Job Satisfaction
* Attrition by Education
* Attrition by Years at Company

## 🛠️ Tools

* Power BI
* Power Query
* DAX
* Data Visualization

## 📌 Dashboard

The dashboard provides an interactive view of employee attrition with filters and KPIs to explore the data from different perspectives.
